# 🌐 Project Overview

> ## What will work look like in 2030?

Artificial Intelligence is changing how organizations operate, the skills employers value, and the types of jobs available across industries.

**The Future of Work 2030** is an interactive Tableau analytics project that explores these changes through data.

The project analyzes:

- 🤖 AI adoption across industries
- 💼 Job automation risk
- 📈 Industry growth
- 💰 Salary trends
- 🧠 Skill demand
- 🏠 Remote-work opportunities
- 🏢 Company-size patterns
- 🎯 Workforce recommendations

The goal is to transform workforce data into **interactive visualizations, meaningful insights, and actionable recommendations**.
